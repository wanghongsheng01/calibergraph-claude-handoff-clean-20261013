### P1-01：值域与良类型前提尚未作为片段定义明确列出

【证据·静态核对】§1 列出 NOT NULL 和 PK/FK，却未给出域容量或列类型兼容条件；§2.3 只说采用相等性域标签，随后要求不同变量标签互不相交；§2 的结论量化所有正整数 n；§7 canonical DB 又要将所有变量冻结为不同值（`THEORY.zh.md:9–13,31,47–49,131–133`）。因此文本强烈暗示抽象无限域，但不足以作为“SQL 有限类型也覆盖”的形式化承诺。

【判断·手推】若每列被理解为固定有限 SQL 域，任意 n 的声明不能成立。更根本地，若 x 的类型只有一个非空值，则 `R(k,x)`、PK(k)、H 为空、M={x}、N=∅ 在每个合法库上重数相等：R 为空时两侧均无输出，非空时均为 1；只按 k→x 算的闭包却不同。这是暴露缺失前提的数学论证，没有生成新 fixture 或执行新 test。若同一变量跨越无公共可取值的列域，body 会不可满足，两侧计数恒零，也不能直接应用必要性或 canonical 冻结。

修复：在正式片段及机器可读结果同步明列“有限数据库、共同无限不透明相等域；输入良类型、无隐式类型转换或额外域限制；本轮不认证实际 SQL 有限域/枚举域”。若选择多类型版本，则另列每个变量各出现位置兼容且可选择所需标签的条件；不要把“某一个 n 有足够值”写成所有 n。仅需要 T(2) 时，容量条件可以更弱，但本次不替作者提出新的最弱域定理。将原先无条件 `PROVED_BY_HAND_ON_STATED_FRAGMENT` 改为补充此前提后成立，并记录初审修正。

### P1-02：声称包含完整 schema 读取的线性上界缺输入项

【证据·静态核对】§3 定义 L 为 body 的变量出现数、f 为 FK 元数据长度、v 为变量数，声称包括完整 schema 读取，随后给 `O(L+f+v)`（`THEORY.zh.md:67–78`，`theory_result.json:theorem.construction_cost`）。但片段允许 B 外的表，且有序 H 未禁止重复位置。

【判断·手推】保持一个小 B、没有 FK，可以增加任意多未用表/列，L、f、v 不变；读完整 schema 已需额外时间。也可在 H 重复同一个 body 变量任意多次，比较/输出 head 的长度并不受 v 界定。闭包、分量和两行见证本身的线性证明不受影响，遗漏在接口总成本。

修复：令 S 为实际读取的完整 schema 编码长度，h 为有序 head 的位置数，明确整数 ID/字长模型，使用 `O(S+L+h+v)` 或直接 `O(完整输入编码长度)`。若 M、N 非紧凑集合表示，也须计其读取长度。两行见证的单元格数仍为 ≤2L；`O(L log(v+1))` 只描述标签单元格写入，不应被当成包含表标识、schema、重复 head 或解析开销的整个交付物位成本。原稿已正确把显式闭合 body 大小计入 L，也正确排除了隐含 chase 成本。

## 3. 主定理的独立证明链审核

以下均为【判断·手推】，以 P1-01 所述抽象无限相等域为条件；不是给原稿补一条未经披露的证明。

1. **充分性成立。** 固定合法 D 和 h，任意两满足赋值在一个 atom 的完整 key 变量相等，就由 PK 在该 atom 全部变量相等。迭代得到任意 T 到 cl(T) 的唯一延拓，因此可延拓投影集合与其闭包投影双射。两闭包相等时逐 head 计数相同；完整满足赋值可有多个隐藏 witness，此处没有数错对象（§2.1）。
2. **差异变量选择成立。** 若两方向的计数变量均在另一闭包内，则单调性给闭包相等；异闭包时至少可选一个方向的 m。H∪N 包含在 C 内，选定分量 S 与其不交（§2.2）。
3. **完整 PK 成立。** 遇到 S 的 atom 至少有一个 key 变量在 S：若所有 key 都在 C，闭包性将整个 atom 放入 C；若 key 在 C 外，它与 atom 中 S 变量同超边，必属 S。因而不同索引在完整 key 至少一位不同。复合 key 无须每一位唯一；重复 key 变量也不改变该论证（§2.4）。
4. **完整 FK 成立。** 每个 FK 都按完整有序元组与唯一显式目标 PK 逐位对齐。用同一个 γ_i 生成所有 atom，便已物化所需目标。复合 FK、源/目标字段重叠、PK/FK 字段重叠、多条 FK 及共享目标都逐条适用；没有“只检查一个分量”的捷径。同表只有一个 atom 避免合并不同 atom 产生的交叉 PK 冲突。未用表为空而无出边源行；来自 B 的所有出边目标按闭合前提均在 B（§2.4）。
5. **恰 n 个满足赋值成立。** 自连接自由使每个关系位置只能读取该 atom 对应变量的生成值。S 外变量均固定；遇 S 的 atom 只能选一个行索引；共享 S 变量要求两端索引相同，连通性将整个分量同步。其他分量全固定，不产生乘积自由度。反向每个 γ_i 显然满足 B，故全体恰为 n 个（§2.5）。
6. **计数与界成立。** M 读到 S、N 不读到 S、H 固定，于是 n 对 1；取 n=2 得每表≤2行，总≤2|B|。精确总行数为 `a+(n−1)s`，不需枚举或求值器性能假设（§2.5、§3）。

FK 图森林不是这段构造在“已经显式闭合”之后使用的必要条件；作者已经明示这一点。不能因此跳过输入守卫、接受 chase 后出现的自连接，或声称未知 chase 规模已被线性成本覆盖。

## 4. 不同 body 的扩展、边界与 fixture

【判断·手推】§7 的边界引理成立：对 B1 作互异变量冻结，每表最多一行，PK 自动成立、显式 FK 闭合使 FK 成立。其 head 必由 set-equivalent 的 B2 返回，于是取得保持 head 的 B2→B1 同态；反向同理。双向同态保证相同关系符号集，自连接自由保证任一自同态逐列固定唯一 atom，而安全性覆盖全部变量，两个复合映射因此都是恒等映射，得到变量同构。沿同构运输计数变量集合后，才可使用共同 body 定理。这一步依赖相同 schema、合法 canonical DB 及 P1-01 的域解释；它没有借用不适用的 bag set-chase。
