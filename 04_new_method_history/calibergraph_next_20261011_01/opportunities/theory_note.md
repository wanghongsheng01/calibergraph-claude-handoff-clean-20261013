# 非键 EXISTS 的单 witness 克隆：作者探索记录

日期：2026-10-11。角色：理论作者探索，不是独立审核。项目主题仍为 UNCOMMITTED。

本文的数字都是冻结前人工推导，尚无本 worker 的执行结果。实验结果仅可来自父任务冻结后执行生成的 results.json。本文只处理一个机制：选取每个外层键的一个 existential witness，再同步复制 witness 键并补外键。

当前建议：REJECT singleton-witness mechanism；REJECT fixed-leaf decidability / computable-bound-existence novelty；更宽树形片段的显式界为 HOLD / UNPROVED。这不意味着不存在合法小反例界。

## 1. 精确目标与尚未成立的命题

设 Σ 为固定有限关系模式，其基表都是集合，每表声明主键，所有外键引用目标表的完整主键，关系级外键图无环。只允许等值连接、正 EXISTS、外层 bag 投影或 COUNT(*)；不允许 NULL、否定、SUM、HAVING、值域顺序或不等式。

为避免“树形”含混，可先把待讨论类 G 定成：每个查询的外层是 counting CQ；至多一个 EXISTS，其内部关系原子图是一棵树；每条树边通过恰一个共享变量连接，所有共享变量的出现满足连通性；内层只通过一个相关变量连接外层，该变量至少在内层入口原子的一个非键位置出现。查询常量与变量相等可以先规范化；若导致树结构不再满足定义，输入退出本片段。G 可以保留自连接，但必须按原子出现而非关系名检验树。此次实验只检查 G 的最小叶型实例，不能检查 G 全体。

**待证目标 T，不是定理：** 存在从 Σ 的有限描述及查询长度 n 有效计算的函数 BΣ(n)，使对任意兼容 Q1、Q2∈G（各自语法长度≤n），若存在有限合法数据库 D 和输出元组 a 满足

    μ(Q1,D,a) ≠ μ(Q2,D,a)，

则存在有限 D'⊨Σ 及 a'，同时满足

    μ(Q1,D',a') ≠ μ(Q2,D',a')；
    对每个基表 S，|S(D')| ≤ BΣ(n)。

对全局 COUNT(*)，μ 直接指聚合前 bag 的总行数。输出 a 不能通过投影成别的常量被偷偷合并。此目标明确要求同一个 D' 对两查询保留差异；“Q1 仍非空”远远不够。

**候选构造所需的更强命题 C，也未成立：** 从查询对有效生成有限个种子及有限维索引复制模板；种子/模板数、维数、各模板的索引支持集合均由查询语法决定。模板把 witness 的新键作为外层复制索引的函数，并生成所有必需外键行。若 Q1、Q2 不等价，则某个模板族在某个有界参数点上分离二者。

不能用“为每个外层键找到了 witness”代替 C。固定单 witness 模板族已经被下文人工反例否定；现在没有另一个已冻结的新构造。

证明义务必须分别交付：

1. **语义规范化。** 外层哪些赋值被 COUNT 计入，哪些内层变量被 EXISTS 消除；任何 key demotion 都要证明保留 multiplicity。不能把整个 EXISTS 直接展平为普通 bag join。
2. **键兼容性。** 不同外层复制要求不同非键值时，witness 主键必须相应分开；同一主键不能承载冲突的行。额外复制的键若也是别表 FK，会改变补行集合。
3. **外键闭包。** 补齐所有 FK 后仍合法，且有受控大小。外键无环只保证深度有限；若一行有多个外键，必须计入分支，不能只乘“最大深度”。安全的粗计数可按全部有向 FK 路径之和计入每个初始行。
4. **双方赋值控制。** 所有新增、合并或删除的行会同时改变两查询；必须证明新增的 Q2 赋值不会抵消 Q1 原来的优势。保存一个存在性 witness 不控制竞争查询的 witness 数。
5. **分离完备性。** 若原数据库存在差异，所生成族至少有一个非零差异函数。这个义务是本轮实质缺口；下文证明最直接的单 witness 族不满足它。
6. **有限提取。** 只有在差异函数非零以及精确的次数界已经证明后，才能用有限网格提取参数界。观察到 2 个或 4 个副本能成功不构成次数或大小定理。
7. **先例排除。** 先检查该片段能否经有限、保语义的投影 view 扩张归约到已有可判定片段。若仅重获已有 decidability 或 computable-bound-existence，拒绝该新颖性主张。

一个可用的**条件引理**很简单，但不解决义务 5：假定某个模板族对所有正整数参数 N 合法，且差异 P(N)=μ1(N)−μ2(N) 为非零多项式、每个 Ni 的次数≤di，则网格 Ni∈{1,…,di+1} 中存在 P≠0 的点。若每个关系 S 的模板 t 产生至多 ∏i∈It Ni 行，则见证大小≤maxS Σt∈S ∏i∈It(di+1)。证明是逐变量应用一元多项式根数界，再代入行数上界。当前没有证明所提 witness 函数构造满足这些前提，尤其没有证明差异多项式非零。

## 2. 唯一机制 falsifier：人工最小 branching fixture

模式：R(r PRIMARY KEY)；W(w PRIMARY KEY, r REFERENCES R(r))。唯一 FK 为 W→R，无环。

    Qexists = SELECT COUNT(*) FROM R
              WHERE EXISTS (SELECT 1 FROM W WHERE W.r=R.r)
    Qjoin   = SELECT COUNT(*) FROM R JOIN W ON W.r=R.r

两个查询的支持条件相同：有 root 带至少一个 witness。聚合前可等价地投影同一个固定标记，其 bag multiplicity 不同。Qexists 的 r 是被计数变量，却出现在 existential W 的非键位置，正好落在待查机制上。

最小合法原实例：

| 表 | 行 |
|---|---|
| R | (0) |
| W | (0,0), (1,0) |

人工计算：Qexists=1，Qjoin=2。每表至多 2 行。至少需要两个 W 行才可能出现此差异，因为 FK 保证每个 W 对应一个 R，而单 W 时两个计数均为 1。

按最小 w 为每个 r 只保留一个 witness，得到 W={(0,0)}；R 不变。此时仍合法，Qexists 仍为 1，但 Qjoin 变为 1，原差异消失。这同时否定“合法性 + 保存 Qexists 的结果就够了”和“任意单 witness 缩减会保留反例”。

对这个单 witness 种子同步克隆，令 Rn={0,…,n−1}，Wn={(i,i):0≤i<n}。对每个 n≥1 都有 Qexists(Rn,Wn)=Qjoin(Rn,Wn)=n。这个结论可以逐行证明，不依赖实验。worker 只检查 n=1、2。即使把 n 无限增加，该特定族仍无法展示原来的 1 对 2 差异。

这没有反驳允许一个 r 对应多个 w 的构造、使用其他种子的构造，或 pair-aware 的更复杂构造。本轮不提出第二个候选机制来绕过已经出现的反例。

作为同机制的合法性检查，若复制 r 时保持 witness 键固定，R={(0),(1)}、W={(0,0),(0,1)} 违反 W 的主键。给两个 W 换不同键修复合法性，却得到上面的同步克隆族，因此“修复键冲突”本身也不修复分离完备性。

## 3. 与完整 tiny-domain 枚举的冻结对照

固定 r∈{0,1}、w∈{0,1}。选择 R 的任意子集；每个 w 独立地 absent 或指向已有的 r。数据库数严格为

    Σk=0..2 binom(2,k)(k+1)^2 = 1+8+9 = 18。

这不是随机样本，也没有同构剪枝。每个固定域合法实例有唯一生成路径：R 决定 root 子集，W 的主键决定每个 w 至多一个去向，FK 只允许去向在 R 中。因此枚举覆盖完整且无重复。

对原始输入，Qexists≠Qjoin 当且仅当两个 W 键都存在且指向同一 r。R 是单元素时有 2 个这样的实例；R={0,1} 时有 2 个；总计 4。单 witness pruning 保留 Qexists 的计数，同时令 Qjoin 等于 Qexists，因此 4 个差异全部消失。以上是冻结前预期，不是测量结果。

协议文件 theory_protocol.json 固定查询、枚举、变换、2 个 clone 参数、18/4/0/4 预期、评估器、预算和停止条件。code/theory_fixture.py 使用纯 Python 求值并逐实例对照 SQLite 的 COUNT；SQLite 显式启用 FK 并声明两个主键。它只向父任务提供的 CALIBERGRAPH_RUN_OUT 写 results.json，自报 RUSAGE_SELF，拒绝覆盖已有结果。父任务须先 hash freeze 再执行；作者未运行。

任一语义不一致、非法实例、超预算或非预期计数导致立即停止并标记 harness/budget 失败。出现预定 falsifier 后，只完成已经冻结的 18 个枚举和 2 个 clone 检查；不扩大域、不换 seed、不调参、不发起 solver/GPU/API。反例结论只拒绝这个确定的单 witness 机制。若某查询对在 18 个实例上没有差异，唯一允许的结论是此固定域未找到反例，绝不能回答无界等价。

## 4. 对固定叶型的经典归约：可计算界“存在”不足以新颖

[Few Rows Tell Them Apart, §4](https://arxiv.org/html/2609.09978#S4) 把非 key-anchorable 情形的难点放在合法 realizability 与 multiplicity 分离上。这个起点不能替代对经典 constrained-equivalence 归约的排查。

[Chirkova 与 Genesereth, PODS 2009, §6.1–6.2](https://arxiv.org/html/0812.2195#S6) 的 Theorem 6.2 给出 set-chase 终止前提下的 bag-set CQ 等价归约；Theorem 6.5 处理兼容 COUNT 查询。以下是本作者的具体归约推导，不是原文声称已经处理本 SQL 语法。

对本轮固定模式新增一个集合关系 E(r)，全列为键，并添加：

    δ1: W(w,r) -> E(r)
    δ2: E(r) -> exists w W(w,r)

原模式合法数据库 D 恰有一个 E 的合法解释，即 E(D)={r:存在 w 使 W(w,r)}。理由：δ1 迫使 E 包含所有 W.r，δ2 禁止 E 包含其他 r。该扩张有限，且不更改原基表；反过来任何扩张模型投影到 R、W 后都是原模式合法模型。因此原输入与扩张输入的量化域双向匹配。

在扩张模式中，Qexists 改成 COUNT(R JOIN E ON R.r=E.r)。E 是集合且 r 为全键，每个 root 最多有一个匹配，所以每个原 EXISTS 成立的 root 恰计数一次。Qjoin 保持原样。此转换逐数据库、逐 multiplicity 保语义；它不是把 W 的多重 witness 错当一次。

固定模式的 TGD 位置图包含普通边 W.r→E.r、E.r→W.r、W.r→R.r；δ2 的唯一特殊边是 E.r→W.w。W.w 没有返回 E.r 的路径，所以没有经过特殊边的环；键 EGD 不生成新值。也可直接观察 restricted set chase：每个 r 至多建立一个缺失的 W witness，已有 W 的 δ1 只补同一 E，不产生新的 r。故有终止的 set chase。

**必须分清两种 chase：** δ2 不可直接作为 bag-safe 展开，它可能把一次 E 匹配展开成多个 W 匹配。这里仅用 set-chase 终止满足经典定理的前提；真正用于 CQ bag-set 等价归约的步骤由 PODS2009 的 sound bag-set chase 算法筛选。不能用普通 set chase 结果直接做 bag 比较。

由此，在这个固定叶型及共享投影 E 的转换类上，经典结果已提供等价可判定路线。如果只有“存在一个可计算合法反例大小界”的主张，也不足以构成新颖性：固定 Σ 与语法长度 n 后，按变量/常量重命名规范化，候选查询对只有有限多个；先用该判定过程分类，只对判为不等价的对枚举有限合法数据库直至找到反例；最终取所有反例大小的最大值，得到有效可计算的统一 BΣ(n)。查询常量计入语法长度，模式内固定常量保持名称。该推导给出的界可能极差，不声称闭式、紧性或高效可用。

**严格适用范围：** 当前位置图证明只覆盖 R(r)、W(w,r)、W.r→R.r 及该单个 E 定义。它没有证明额外 FK、多个不同投影视图或更宽树形 existential 部分的扩张仍终止。多个 view 的依赖可能产生新的特殊边环，需要重新分析。因此固定叶型的 novelty 应 REJECT；更宽 G 的闭式/定量界仍为 HOLD / UNPROVED，不能依据本例宣布整个前沿已解决或未解决。

## 5. 决策与可交付边界

- 单 witness 种子同步克隆的分离完备性：人工证明已否定；冻结短测只能复核机制，不能增加其普遍性。
- 固定叶型的 decidability / computable-bound-existence 新颖性：建议 REJECT，理由是上面的保语义扩张与经典定理链。
- 更宽树形片段的显式有效界：HOLD / UNPROVED；尚缺双方差异控制、模板分离完备性、扩张终止边界及真正超出先例的定量结果。
- 不将 FK 补行、反例缩减、约束合成等已知工具重新包装成新机制；不声称自然数据价值、最优性、速度优势或新颖性已经成立。

父任务可以把这份记录作为本方向停止投入的理由。继续研究若发生，必须是之后明确登记的新假设；本轮不会通过增加第二机制、增加搜索规模或弱化 falsifier 来挽救原提案。
