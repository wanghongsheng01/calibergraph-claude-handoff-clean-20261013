# Round 04 exact-shape pilot interface

No worker, SQL, official parser or solver was run during implementation. Only Python syntax compilation without execution of the resulting code was used. Root must bind and freeze `pilot_protocol.template.json`, all code, the resource policy and input/runtime identities before starting any worker. No supervisor is implemented here.

Both worker entry points accept `--protocol FILE --case-index INDEX --out DIR`. Launch the existing native Python 3.12 with `-B -I -S`, nice at least 15, under the root-owned CPU/wall/RSS/solver-progress monitor. `INDEX` is zero-based in `registered_cases`; one process handles one shape. The ten slots are fixed in order: concrete N=1, official N=1, through concrete N=5, official N=5. Each concrete slot includes both NULL and nonNULL CLASS fixtures. There are no separate repeats.

The template contains the actual original round 03 registry, complete `dev03_18` SQL/schema/constraint identities, and frozen runtime lock. SQL strings are read only from the original registry at execution; no handwritten replacement SQL query is used. Common admission rejects any extra or unknown original constraint and any source/hash/order mismatch. Resource fields are 3 CPU seconds, 4 wall seconds, 256 MiB externally monitored RSS, nice 15, one active worker, one attempt, C check 100 ms and query check 700 ms. Both checks count toward the 2.0 second solver wall accounting limit; the external monitor stops completed plus active solver wall at 1.5 seconds. A 0.1 second reserve is applied by the solver budget.

The official baseline creates one cold official Environment and encodes the complete original schema, C and query pair. Official `environment.py:584` appends `NotDeleted` for every physical row, so `N` means exactly N live rows. Those facts remain in the C check and query encoding. No deletion-variable rewrite, up-to-bound claim, extra official fixture constraint, frontend repair or fallback is permitted.

`results.json`, `progress.json` and evidence artifacts are atomically replaced; event entries are flushed and fsynced. Progress fields retain round 03 names: `active_stage`, `latest_stage`, `solver_check_active`, `solver_check_start_monotonic`, `solver_spent_wall_seconds`, `check_count`, `case_index`, `id`, `updated_monotonic`. All cost measures include instrumentation within their measured stage. The parent must retain partial files and classify external interruption as inconclusive.

Official evidence includes original source record and provenance, lossless parsed AST JSON, stage and solver check costs, complete C and query assertion SMT text, raw SAT/UNSAT/UNKNOWN, all submitted-fact/model checks, complete physical model values and full raw model sexprs whenever a SAT model exists. A separate Python check verifies exact N and the full original primary constraint (nonnull, unique STUDENT) on each exported encoded model. VARCHAR values remain encoded symbols; this does not provide independent SQL or natural-business gold.

The concrete worker uses only stdlib and an in-memory SQLite database. It independently checks the complete known original C before insertion and records bag outputs from the two unchanged original SQL strings for all-NULL CLASS, then the same N/STUDENT rows with one nonNULL CLASS value. These are mechanism fixtures on an already exposed development pair, not natural data labels, newly sampled tests or a new research mechanism.

Root must bind the registration timestamp/status, resource and code freeze receipts, supervisor policy and prior CPU charges, and freeze the final protocol hash. Root owns all external launch and stop decisions; the workers do not demonstrate that these external guards were present.
