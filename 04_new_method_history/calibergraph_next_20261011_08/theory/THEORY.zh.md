# Round 08：一个可完全复核、但没有新机制的闭包分离定理

日期：2026-10-11。身份：理论作者，未充当独立审稿者。结论：**机制创新 NULL；获得一个已有方法的完整专门化证明和强控制规范。** 全文为手推；没有运行 SQL、solver、科学程序、模型、GPU 或队列，没有读取任何 finaltest、保留集、基准结果。07 四个输入仅视为未审核假说来源。本报告不继承“可计算即有贡献”或“1/T 排除了与值域无关概率”的说法。

## 1. 唯一研究命题与精确片段

只研究以下输入 `(Σ,B,H,M,N)`，称为本报告的片段 F。不是通用 SQL 前端。

1. 有限表；每表一个非空、可复合的 PK；每列 NOT NULL；FK 引用完整 PK。除了这些约束没有其他约束。FK 的有向图无环，忽略方向后的简单图是森林。
2. `B` 是非空、安全、纯关系合取；只含变量，等号由相同变量表达；没有常量谓词、比较、NULL、UNION、否定、外连接、聚合或基础表 bag。**每个关系符号最多一个 atom。** 允许一个 atom 内重复变量。
3. `B` 已显式 FK 闭合：任一 atom 的任一 FK 都有对应目标 atom，而且引用变量元组与目标 PK 变量元组逐位相同。未出现在 B 的表取空即可。判定不隐含运行 chase、生成新 body 或接受 chase 后产生的自连接。
4. 两个 query 使用**同一个、相同变量命名的 B 和相同有序 head H**，只在计数变量集合 `M,N ⊆ vars(B)\vars(H)` 上不同。没有暗中的 body 同构搜索。其他变量存在量化。空 H 输出常量 unit，每个计数赋值贡献一份 unit。
5. 对每个 head 值 h，输出重数是满足 B 的赋值在 `H∪M` 或 `H∪N` 上去重后的数量。这对应先 `SELECT DISTINCT H,M` 再 bag 投影 H；不是对隐藏 PK 的赋值数。

目标 H08：这个片段能否使用一个合法、保留相关碰撞的依赖式模板，严格优于 Bell/实例枚举，完整判断并分离任意输入对？答案为肯定，但完全落入 FD 闭包与 Armstrong 构造，因此**不是可晋升的新研究机制**。

“超出 key-anchorability”只表示 F 含有不满足该语法条件的实例，并非声称 F 包含 FewRows 全片段。F 的 `同一 body + 无自连接` 限制非常强。下面 F1 两侧均非 key-anchorable；因此这不是把 Theorem 13 的前提偷偷满足后重用其结论。

## 2. 完整定理

令 V 为 B 的变量集。每个 atom A 产生一条变量 FD：

`K_A -> vars(A)`，其中 K_A 是该 atom 的 PK 位置所含变量集合。

记这些 FD 为 F_B，`cl(T)` 是 T 的普通属性闭包。令 `C_M=cl(H∪M)`，`C_N=cl(H∪N)`。

**定理。** 在上面的片段内：

`Q_M ≡_Σ Q_N  当且仅当  C_M = C_N`。

若闭包不同，可从输入直接构造一个一参数模板 `T(n), n≥1`，使每个 n 都满足完整 PK/FK 约束。在某个固定 head 元组上，两 query 的重数恰为 `n` 和 `1`（或相反）。因此只测试 `n=2` 就完整分离。模板数为 1；可写成 Boolean corner family `{T(1),T(2)}`，其第一角恒不分离而第二角必分离。每表至多 2 行，总行数至多 `2|B|`。

### 2.1 充分性：闭包相等使计数投影双射

给定任意合法 D 及固定 h。任意两个 B 的满足赋值，若在 atom A 的 key 变量上相同，由真实表 PK 就在 A 的全部变量上相同。逐条传播可知：在 T 上相同必在 cl(T) 上相同。

故每个可延拓的 `H∪M` 赋值，恰有一个可延拓的 `C_M` 赋值；反向投影也是一一对应。N 同理。当 `C_M=C_N`，两组计数赋值经同一闭包赋值集合双射，逐 head 重数相等。这不要求 B 的完整满足赋值唯一，不会把隐藏 witness 的个数当成答案重数。

### 2.2 必要性：选择差异和一个同步分量

若闭包不同，至少一个方向有 `m∈M\cl(H∪N)`，或交换 M,N 后有此情况。因为若 M 全在 C_N 内，闭包单调性给 C_M⊆C_N；双向都包含则闭包相等。

固定有差异的方向，写 `C=cl(H∪N)`。在节点 `V\C` 上建无向 incidence 超图：每个 atom A 给出非空超边 `vars(A)\C`。取包含选定 m 的连通分量 S。N、H 都与 S 不交，M 与 S 相交。一个 atom 如果遇到 S，其所有不在 C 的变量都属于 S；这是连通分量定义的直接结果。

### 2.3 模板

不同变量采用互不相交的值标签。每个 `v∉S` 固定为一个值 `a_v`；每个 `v∈S` 有 n 个值 `a_(v,1),...,a_(v,n)`。这些只是相等性域标签，不是有限域权重、NULL、SQL 数值运算或随机样本。

令 `γ_i(v)=a_(v,i)` 当 v∈S，否则 `γ_i(v)=a_v`。对每个 atom A，在对应表插入 `γ_i(A), i=1..n` 并按集合去重。B 之外的表为空。用相同 γ_i 生成所有 atom，保留原 query 的全部变量相等关系。

### 2.4 PK、FK、非空值的完整合法性

不遇 S 的 atom 只产生一行。遇 S 的 atom 一定有至少一个 key 变量在 S：否则 key 全在 C，而 C 对 `K_A -> vars(A)` 闭合会迫使 A 全在 C，与遇 S 矛盾。不同 i 因此在完整 PK 的至少一位不同，不会发生同键异行。每个关系只有一个 atom，故不存在来自同表其他 atom 的交叉 PK 冲突。复合 PK 无需逐分量唯一，只需要完整元组不同。

每个源行 γ_i(A) 的完整 FK 元组等于其显式目标 atom γ_i(A') 的 PK 元组。后者已在模板中；去重不会删除最后一个相同目标。所有值都非 NULL，所有空表无源行，所以全部 FK 均满足。FK 森林是输入限制；证明在已经显式闭合之后不再利用无环性，不能据此声称解决一般 FK chase 成本。

### 2.5 没有隐藏的额外赋值，也没有丢失分离

由于一个关系只有一个 atom，B 的任意满足赋值在每个列位置只能读取该变量自己的标签域。所有 `v∉S` 被迫固定为 a_v。每个遇 S 的 atom 必选一个行索引 i_A；该 atom 内 S 的变量有相同索引。共享的 S 变量又迫使相邻 atom 索引相同；连通性最终使所有遇 S 的 atom 使用同一个 i。

所以 `Γ(B,T(n))` **恰好**是 `{γ_1,...,γ_n}`。没有其它 atom 模板可把固定变量换成别人的值，也没有不同分量的自由组合，因为只变动一个分量。M 至少读一个 S 变量，故产生 n 个不同计数赋值；N 不读任何 S 变量，故只产生 1 个。H 固定，答案差异 n−1 无处被其它 head 或其它 assignment 抵消。

这一步比“找到合法 DB”强：它明确证明了 query 差异。若隐藏 key k∈S，可写 `k=f_k(m)`，其中 `f_k(a_(m,i))=a_(k,i)`；k∉S 则为常函数。依赖集只有 `{m}` 或空集，但所有函数共享同一索引。原变量相同的出现使用同一函数；不同变量使用不同标签。固定变量上的碰撞被刻意保留。这个构造**只为本输入对造一个分离 DB**，不声称把任意已有 DB 函数化以后仍保持所有 query。

## 3. 从输入到模板的成本

令 a=|B|，L 为 atom 中总变量出现次数，f 为 FK 元数据总长度，v=|V|。包括完整显式 body 与 schema 的读取成本；不把 FK closure 大小藏在深度参数里。

| 步骤 | 可核验成本 |
|---|---|
| 检查共同 body/head、无自连接、NOT NULL、PK/FK及显式闭合 | 用变量/关系 ID 和索引表，O(L+f+v) word operations；未通过直接 OUT_OF_FRAGMENT |
| 建 F_B，分别算两个闭包 | key 待定计数和变量邻接表；每条 FD 至多触发一次，O(L+v) |
| 选差异变量，找 S | O(L+v) |
| 模板数量 / 搜索 | 1 个模板；不枚举 equality type、DB 或依赖集；没有 solver/PIT |
| `T(n)` 行数 | `a+(n−1)s`，s 为遇 S 的 atom 数；每表≤n |
| `T(2)` 构造与精确结构检查 | O(L+f+v) word operations；≤2L 个单元格 |
| 标签与输出 bit cost | 标签 O(log(v+1)+log n) bits；n=2 的写入 O(L log(v+1)) bits |
| 两个输出 | 由证明直接为 2 与1；不要求黑箱 SQL join 优化器具有线性成本 |

通用 evaluator 最坏仍可指数枚举变量赋值；上面的线性输出校验来自已证明的模板结构，不能挪作任意实例评估复杂度。若 n 是二进制大参数，物化仍付 Ω(nL)；本算法固定 n=2。等价情形直接输出闭包证书，无需采样。相比 Bell 枚举是真实界改善，但改善来自标准闭包算法和两元组 FD 反模型，不能据此宣称新算法。

## 4. 四个核心手写例与一个最小越界反例

完整冻结输入在 `fixtures.json`；全部未执行。

**F1：非 anchored、共享父键、同一计数值进入两个隐藏 child 关系。**

`P(p PK)`；`C(c PK,p FK,x)`；`D(d PK,p FK,y)`；`E(e PK,p FK,x)`。

`B=P(p) ∧ C(c,p,x) ∧ D(d,p,y) ∧ E(e,p,x)`，H=unit，M={x,y}，N={x}。x 在 C、E 的非 key 列，y 在 D 非 key 列；两侧 counted-only-key 集合均空，空 head 的闭包不能包含 x 或 y，故两侧均不 key-anchorable。C_N={x}，S={p,c,d,e,y}。

手写行：P={11,12}；C={(21,11,7),(22,12,7)}；D={(31,11,8),(32,12,9)}；E={(41,11,7),(42,12,7)}。两侧重数分别2、1。所有 key 唯一，每个 FK 精确指向 P；两父组共享 x=7，这是保留的碰撞。该小例仍可删私有 c,d,e 而保留 p，化成无约束 set projection 加冗余 unary parent；所以“共享隐藏父键”本身也不构成新障碍。

**F2：闭包相等且非 anchored。** `X(x PK,y), C(c PK,x FK)`，共同体 `X(x,y)∧C(c,x)`，M={x}，N={x,y}。两闭包都为{x,y}；c 隐藏。X={(11,7),(12,7)}，C={(21,11),(22,12),(23,11)} 时两侧都是2。任意合法实例上的等价由闭包证明，而非由此五行样例推断。

**F3：复合 PK/FK。** `P(a,b,z) PK(a,b)`；`C(c,d,a,b,x) PK(c,d), FK(a,b)→P`。共同体两个 atom；H=(a)，M={x,z}，N={z}。C_N={a,z}，S={b,c,d,x}。P={(1,11,7),(1,12,7)}；C={(21,31,1,11,8),(22,32,1,12,9)}。head=1 下重数2、1。只检查 FK 的 a 分量是不够的；本模板逐位检查完整(a,b)。

**F4：无自连接条件不可删；最小反例不是自然 bug。** 用全元组 PK 的二元表 R，体为 `R(x,y)∧R(y,x)`，M={x}，N={y}，H=unit。两个 FD 闭包不同，但 query 在任何数据库上等价：交换 x,y 给满足赋值双射，两种投影值集合实际相同。错误延伸上述模板会产生 R={(11,7),(12,7),(7,11),(7,12)}；两侧实际重数都为3，而不是2、1。固定 y=7 被另一个同表 atom 的行重新赋值为11、12。全部 PK 合法，却丢掉分离，精确暴露“隐藏键函数化合法 ⇒ 完备”的推理漏洞。本片段必须返回 OUT_OF_FRAGMENT；这不是对所有可能自连接分离算法的不可行性定理。

另有 F5 未显式 FK 闭合、F6 不同 body、F7 允许 NULL，均固定预期为 OUT_OF_FRAGMENT。不能因为还能手工修复就扩大本轮分母或自动改片段。

## 5. 最近邻判定：立即 NULL

- **Armstrong 两元组先例。** Beeri–Dowd–Fagin–Statman 1984 §3 Lemma 3.1 及紧随其后的构造已给出：在 X 的 FD 闭包内保持相同、闭包外改变的两元组反模型。本报告把它分投影到无自连接的 query atoms，并验证 FK 与计数，属于直接专门化；连通分量版本只使输出恰为 n 与1。[原文](https://www.researchgate.net/publication/220431370_On_the_Structure_of_Armstrong_Relations_for_Functional_Dependencies)
- **FewRows 2026。** §4 Lemma 11 已用 FD 决定计数变量的 demotion；本定理充分性就是同一投影双射。Theorems 13/15 限 key-anchorability。该节最后的客户—订单文字描述非 anchored 的一般残余问题；本报告仅处理共同无自连接 body，不能声称关闭该一般问题。F1 的投影消去还让 §3 无约束结果直接适用。[原文](https://arxiv.org/html/2609.09978v1#S4)
- **DeHaan 2009。** Appendix A.2 已有 diversification multiplicity polynomials 和随机正整数网格分离。本轮只有确定的一次函数差 n−1，既无新的 PIT，也无概率优势。[原文](https://uwspace.uwaterloo.ca/bitstreams/75481061-96ae-4f14-89b7-44c6aab72683/download)
- **Chirkova–Genesereth 2009。** Theorems 6.1/6.2 是终止条件下的 sound bag/bag-set chase 等价规约。不能把它们直接引用成一般 partial-counting 定理；它们已封住“约束 chase + 已知等价方法”的泛架构创新。本报告不提出新 chase。[原文](https://arxiv.org/html/0812.2195v3#S6)

普通 FD 投影冗余规则直接处理 F2 与本定理充分性；Armstrong 反模型处理必要性。既然成熟方法已覆盖本候选的全部关键步骤，立即停止机制晋升。无需再包装成 bounded-treewidth、CSP、泛 Skolem atlas 或新随机族。

## 7. 放开“同一 body”时，证明首次在哪里失效

充分性第2.1节首先需要把两侧的投影都与**同一个满足赋值集合**的闭包投影建立双射。body 不同就没有这个共同集合；仅有相同变量名、相同 FD 或相同闭包都不能补上。

一个 atom 已足够展示错误延伸。表 `R(k,a,b)`，PK=k；`B1=R(k,x,y)`，`B2=R(k,y,x)`；H=unit，两侧都声明 M=N={x}。两侧变量 FD 都是 k→x,y，闭包都为{x}，而 R={(1,7,8),(2,7,9)} 时答案重数为1、2。两 body 的 Boolean 支持完全相同，表无自连接、无 NULL、FK 闭合真空成立。它们虽然可按 x↔y 进行 body 对齐，**计数变量必须随映射运输**，对齐后 M={x},N={y}，本定理正确判断不等价；不经运输比较同名闭包就是错的。

若关系符号也可不同，最小的 `R(x)` 与 `S(x)`、两侧计数{x}，在 R={1},S=∅ 上也立即失败；该例还展示 set 支持会不同，不能用于反驳附加了 set-equivalence 的命题。

**精确边界引理（成熟规约，未扩 fixture）。** 保留本报告所有 schema、纯变量、无自连接与显式 FK 闭合条件，允许 B1、B2 不同；若它们作为 set queries 在合法 DB 上等价，则必存在保持有序 head 的变量重命名同构。因而沿同构运输两侧计数集合后，确实获得共同 body，前述定理适用。

短证：把 B1 的每个变量冻结为不同标签，得到其 canonical DB D1。每表最多一行，故 PK 满足；显式 FK 闭合保证所有目标存在，因此 D1 合法。B1 自己给出的 head tuple 必由 B2 返回，所以 B2→B1 有保持 head 的关系同态 f。同理由合法 D2 得 g:B1→B2。双向同态先强制两个 body 有相同关系符号集合。由于每表只有一个 atom，任何 body 到自身的同态都必须逐列把唯一该表 atom 映回自己，因安全性而固定所有变量。因此 f∘g 与 g∘f 均为恒等映射，f、g 互逆，正是所求同构。它们同时运输 head 和 counted set，故不改变 combined 语义。证毕。

这是经典 canonical-DB/set-containment 论证的直接特例；[Chirkova–Genesereth §2.1](https://arxiv.org/html/0812.2195v3#S2.SS1)陈述通常的同态判据。此处 canonical DB 自身已经合法，无需把 bag set-chase 的正确性偷渡为 partial-counting 正确性，也不用额外调用 solver。匹配同名关系的对应列并核查一致/双射与 head，即可在线性扫描内找唯一可能的重命名。F6 是提醒必须运输 counted set，不是对这个引理的反例。引理既没有覆盖自连接、未闭合体或其它约束，也没有改变冻结的七项原始接口测试；在那一接口上未对齐 body 仍应拒绝。

所以，在上述全部前提和 set-equivalence 下，“不同 body”并没有留下一个新的机制缺口；它被已有的 canonical-DB 规约消去了。超出这些前提的 pair 本轮只给 OUT_OF_FRAGMENT，不另起泛候选。
