Strict TRUE is required for every clause on every exact physical row; NULL fails. This is an explicit experiment contract, not an inferred SQL CHECK convention.

Only a normalized copy reaches actual Environment.add_constraints. Literal-left ordered comparisons swap direction; eq/neq preserve their operator.
