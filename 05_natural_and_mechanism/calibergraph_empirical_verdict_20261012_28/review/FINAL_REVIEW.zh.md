# 独立窄审：实证稿类型裁决

**ACCEPT_WITH_LIMITATIONS。** 这是对本次一页裁决可用性的评价，不是论文录用判断。没有阻断性交付问题；支持维持当前 HOLD，理由是尚未建立足够的系统性 SQL 新知识，而不是没有新算法。

【证据·原稿报告】裁决第 7 行与 `results_current.tex` 的六臂结果、`sqlite_case_study.tex` 的 natural/Polygon/COUNT 三张表相符：selector 22 对 flat 23；10 对保留两对无效输入，8 对有效中的 4 对进入适配 Polygon；两对具体 NEQ、两对有界 UNSAT；42 个暴露回归未运行完整编码流水线。本审阅未重算这些实验。4/8 不是跨工具准确率，人工见证与回归数也不能充当独立自然缺陷数。保留这些结果有价值，但它们目前没有形成可迁移的规律或充分刻画的覆盖边界。

【证据·直接阅读】P19 本地稿第 22、36、40–49、160、177、308、346–352 行支持逐项边界：契约分层、unknown/拒绝、独立 checker、哈希与重放已有明显贡献重叠；其参考投影明确未执行 SQL 或证明聚合语义。第 13–16 行因此诚实地区分了“研究对象可区分”和“本稿尚有新贡献待建立”。本次核得 P19 SHA-256 与收据一致；这不能认证实际投稿版本，更不能代替逐文本、数据、图表的全量重叠比对。

【证据·来源范围】官方 [DKE 介绍正文](https://shop.elsevier.com/journals/data-and-knowledge-engineering/0169-023X)可读，列有 applications/case studies；据此排除“无新算法即不适合 DKE”的绝对说法是合理的。两篇对照均只被声明为出版页索引摘要/节选，完整结果表未得，作者指南未核验；收据没有冒称全文阅读或复现。本审阅直接打开两篇出版页亦为 403，搜索未独立取回其有效索引节选，因此不额外认证两篇论文的细节，只确认当前披露范围没有被包装成全文核验。

【判断·轻微措辞建议】第 5 行“该文表明系统数量不是硬门槛”略强于摘要/节选能支持的期刊规则推断。建议改成：“这些可读材料不能推出固定的系统数量门槛；本裁决关注可复用评估对象及明确的新知识。”这不改变裁决，也不要求补读全文或再找对照。

【判断·唯一补实验】第 18 行的跨工具端到端矩阵能改变判断：它可能把若干个案提升为跨 schema 的 SQL 语义规律或有用的覆盖边界，阴性结果同样可能有贡献。决定因素是共同语义域、完整约束、原生/适配分离、独立见证复核与失败分母，不是做满 60 对/6 schema，或必须凑出三个工具。该规模和工具组合应仅作此轮提出的候选设计，不能升级为期刊硬门槛、功效结论或唯一可成稿路径。无共同准入时应先停在可行性预检，不得改成只保留成功交集的比较。单次实验成功也不保证新颖性或投稿准备完毕。

【判断·今晚】第 20 行没有承诺今晚可完成，且把语义准入、oracle 和预算预检放在启动之前，合理。数据条目足够并不证明合格实验已就绪。本审阅未运行 SQL/parser/solver/benchmark，未改作者裁决、原稿或 P19；未扩大候选或综述。
