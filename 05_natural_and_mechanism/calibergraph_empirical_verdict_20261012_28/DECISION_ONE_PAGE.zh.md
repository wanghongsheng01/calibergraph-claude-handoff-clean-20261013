# CaliberGraph：独立实证稿的一页裁决

**裁决：现有证据不足以支撑独立的系统性实证稿；该论文类型本身可行，当前为 HOLD，不建议今晚改写投稿。** 不应继续以“没有新算法”作为唯一否决理由，也不能把失败算法换一个实证题名便算新贡献。

**期刊与证据尺度。** 已直接读取 [Elsevier 官方 DKE 介绍](https://shop.elsevier.com/journals/data-and-knowledge-engineering/0169-023X)，确有 applications、case studies 和技术进展；作者指南本次仍为 403，未核验。目的性选取两篇正式发表的相邻系统评估论文，只作尺度对照，不推断录用标准：① [Chaloupka–Necaský，DKE 152 (2024), 102309](https://doi.org/10.1016/j.datak.2024.102309) 统一 BSBM 对虚拟 SPARQL 端点的使用，比较部署、正确性、性能，提供重复评估脚本并解释结果；已核出版页索引中的摘要、引言和评估节摘要，未取得完整结果表，故不报系统数或运行规模。② [DLBench+，DKE 145 (2023), 102154](https://doi.org/10.1016/j.datak.2023.102154) 有文本/表格数据模型、规模参数、10 类任务/20 个查询实例、定量与用户体验协议，并以 AUDAL 作概念验证。其可读出版摘要并不支持“多系统全面胜出”；这些可读材料也不能推出固定的系统数量门槛。我的判断是应看可复用的评估对象与明确的新知识。以上均为论文报告，未复现实验。

**现有证据能说明什么。** 28 个暴露配置的六臂结果、完整失败分母和 selector 22 对 flat 23，足以保存一个诚实的受限编码负结果；48,910 查询槽只支撑自身前端的准入边界，不能变成跨工具可靠性样本。自然集 10 对中 8 对有效、4 对进入适配 Polygon，仅得两对具体 NEQ 和两对有界 UNSAT；另 8 个手造见证来自 3 对 SQL。约束方向反例和 42 个 COUNT 回归有工程价值，但后者未走完整编码流水线。尚无公平、广泛、原生路径与适配路径分离的 SQL 语义实证矩阵，也未建立可迁移的失效规律。新 pairdiff 的 138 对自然 JOIN 是结构统计，不补此缺口。

**P19 逐项边界。** 本次实读指定本地修订稿的摘要/贡献、两项外部审计、reference、讨论与局限，哈希与旧记录一致；未认证其与实际投稿版本相同。

|拟用贡献|与 P19 的关系|
|---|---|
|比较契约、证据分层、unknown/拒绝、版本限定审计|P19 已是核心贡献，不可重报。|
|独立 checker、快照哈希、重放与保留负结果|P19 已覆盖；新增日志数量不是新知识。|
|SQLite NULL/类型亲和性/bag/聚合及完整约束在实际工具链中的保真与失效分布|P19 明确未执行 SQL 或证明聚合语义；对象可区分，但本稿尚未形成系统性发现。|
|文本、实验数据、图表和对照|不得把 P19 的内容或数据冒充本稿新增贡献；必要复用须明确引用与披露。未做逐文本/数据全量比对，**不宣称无重叠**。|

**最少还缺的一个真实实验。** 一个预登记的跨工具端到端可靠性矩阵：固定 BIRD 1,534 对/11 个 schema 的来源分母，按 schema 与 SQL 语义类别无结果筛选地取样，建议起始 60 对、至少 6 个 schema（研究设计建议，非 DKE 门槛或功效证明）；评估 Polygon、ParSEval 及一个完成保真准入的独立实现，先核代码谱系，不能把 Polygon/VeriEQL 或同工具两种模式算独立系统。保留原生与最小适配两条路径，在共同语义域匹配完整 C、行数界和资源；比较合法且实际区分原 SQL 的见证产出、声明与重放冲突、覆盖和成本，失败均入分母。抽样无差异不能叫一般 EQ；有界 UNSAT 不叫无界 EQ；超出工具声明方言的差异不叫原生 bug。所有见证由独立方复核；留新执行的验证组并披露已有静态暴露，不冒称全新未见 test。只有得到跨 schema 可重复的 SQL 特有规律或有用的系统覆盖边界，才足以重新评估实证稿；可以是阴性结果，不要求发现更多 bug 或超过 baseline。孤例、纯适配收益仍不足。

**今晚可行性：数据条目足够，合格实验尚不具备。** 本地已核到上述 SQL 与 11 个 schema，但没有 60 对多工具共同语义准入及独立 oracle 的证据，现有运行仅证明 4 对适配 Polygon 可行；广泛类型/约束映射和完整流水线公平性尚缺。不能承诺在不挤占 unrelated_project 的今晚补齐这一个实验，更不能用几秒钟回归代替。今晚应停在此裁决；若以后重启，先完成准入与预算预检。一次该实验也只可能改变“值得成稿”的判断，不保证新颖性、完整论文或录用。本轮未启动实验、未改原稿/P19。
