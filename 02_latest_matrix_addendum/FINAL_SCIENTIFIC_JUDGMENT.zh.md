# 本轮最终科学判断：HOLD

**本轮已完成，整体投稿任务未完成。** 33对、66槽的预登记开发审计已实际执行一次，完整保留分母、输入无效、不支持、未知、超时及见证回放。非作者独立SQLite重放116个候选与作者完全一致。这使跨schema端到端证据从“计划”成为可核验记录；不代表方法、成稿或投稿获准。

**得到的新证据。** ParSEval路径18/33产生有效区分见证，分布于11个schema；Polygon既有pilot13路径1/33产生有效见证。两路径未匹配语义域或行数界，后者25槽停于既有schema映射缺失，不能据18与1排名，也不能把适配覆盖当原生工具覆盖。输出列数不同的一对查询产生了满足源约束却不区分行结果的Polygon候选；原上游源码和保存SMT支持局部分支方向诊断。它是一个可追溯单例，不是失效频率、新机制或新颖性证明。

**为什么仍HOLD。** 现有记录尚未建立“哪一种SQL语义义务，在何种条件下、经哪些实现路径，会系统性改变声明与实际结果之间的一致性”这一可迁移发现。11个schema中都有具体见证，并不等于11次复现同一种失效机制。原生、资源适配与语义修补必须继续分开；本轮只运行两条资源适配路径，Polygon仅三对进入求解。抽样一致不是EQ，有界UNSAT不是无界EQ。所有素材均开发暴露，没有独立最终验证组。

**足以改变判断的发现应是什么。** 可以是一种预先定义、可解释的SQL特有失效规律：在多个schema和真正可比的声明域中重复出现，能区分输入无效、前端限制、编码/解码偏差、搜索预算和比较契约差异，并用针对性反证检查排除混杂。也可以是阴性结果：在明确可比域和足够精确的失败分母下，可靠地界定某类风险没有出现的范围及统计不确定性。两者都需相邻先例/已知缺陷去重、版本和工具谱系披露，以及事先保留、未反复开发使用的独立验证材料。此处陈述证据门槛，不授权任何新实验。

**不要求所有baseline都输。** 实证论文不必提出新算法，也不必让某个方法在所有baseline上获胜。需要的是超过“多跑了一些日志”“修了一个bug”“更换适配器提高覆盖”的可复用新知识；若证据支持现成方法已足够或方法差异消失，也应照实报告。比较契约、checker、哈希、unknown/拒绝等已有P19重叠不能再次包装为本稿新增贡献；本轮未改P19，也未完成全量新颖性/重叠审核。
